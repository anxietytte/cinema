# Документация базы данных Cinema Booking

## 1. Таблица users (пользователи)

**Назначение:** Хранение данных о зарегистрированных пользователях.

**Поля:**
- id - уникальный идентификатор пользователя
- email - электронная почта, используется для входа
- password - хэш пароля
- name - имя пользователя
- phone - номер телефона
- registered_at - дата и время регистрации
- avatar - ссылка на аватар
- is_active - активен ли аккаунт (true/false)

**Связи:**
- users связан с bookings (один ко многим) — один пользователь может сделать много бронирований

---

## 2. Таблица genres (жанры)

**Назначение:** Хранение жанров фильмов для категоризации.

**Поля:**
- id - уникальный идентификатор жанра
- name - название жанра
- description - описание жанра
- icon - emoji иконка
- color - цвет для оформления

**Связи:**
- movie_genres связан с genres (один ко многим) - у одного фильма может быть несколько жанров
---

## 3. Таблица movies (фильмы)

**Назначение:** Хранение информации о фильмах.

**Поля:**
- id - уникальный идентификатор фильма
- title - название фильма
- description - описание сюжета
- poster_url - ссылка на постер
- year - год выпуска
- country - страна-производитель
- rating - рейтинг
- duration - длительность в минутах
- release_date - дата выхода в прокат

**Связи:**
- movie связан с bookings (один ко многим) - один фильм может быть забронирован много раз
- movie связан с movie_genres (один ко многим) - один фильм может иметь много жанров

---

## 4. Таблица movie_genres (связь фильмов и жанров)

**Назначение:** Связывает фильмы с жанрами (таблица для связи многие ко многим).

**Поля:**
- id - уникальный идентификатор связи
- movie_id - ссылка на фильм
- genre_id - ссылка на жанр

**Связи:**
- movie_genres связан с movie (многие к одному) - много связей принадлежит одному фильму
- movie_genres связан с genres (многие к одному) - много связей принадлежит одному жанру

---

## 5. Таблица bookings (бронирования)

**Назначение:** Хранение бронирований билетов.

**Поля:**
- id - уникальный идентификатор бронирования
- user_id - ссылка на пользователя
- movie_id - ссылка на фильм
- status_id - ссылка на статус бронирования
- seats - номера мест
- seat_row - ряд
- booking_date - дата и время бронирования
- session_date - дата и время сеанса
- total_price - общая стоимость

**Связи:**
- bookings связан с users (многие к одному) - много бронирований принадлежит одному пользователю
- bookings связан с movie (многие к одному)- много бронирований принадлежит одному фильму

## Связи между таблицами

### Текстовое описание связей

users (1) ─── (0-*) bookings
movie (1) ─── (0-*) bookings
movie (1) ─── (0-*) movie_genres (1) ─ (0-*) genres

### SQL-обозначения связей (при создании таблиц)

```sql
-- users -> bookings (один ко многим)
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE

-- movie -> bookings (один ко многим)
FOREIGN KEY (movie_id) REFERENCES movies(id) ON DELETE CASCADE

-- movie -> movie_genres (один ко многим)
FOREIGN KEY (movie_id) REFERENCES movies(id) ON DELETE CASCADE

-- genres -> movie_genres (один ко многим)
FOREIGN KEY (genre_id) REFERENCES genres(id) ON DELETE CASCADE
